timeseries-chart

A scrubbing time-series chart whose entire display state is a viewport: centre, span (seconds) and follow. Every input writes that same state. No animation - the chart is a pure function of the viewport, nailed to the pointer.

This page is how you judge it. Try every input on every chart.

Inputs (all of them work on every chart):
  • Drag horizontally to pan. Vertical drag scrolls the page - the axis locks after ~8px and never switches mid-drag.
  • Wheel to zoom, anchored on the pointer. At the zoom limit the wheel is released back to the page, so you never get stuck scrolling a tall dashboard.
  • Trackpad: pinch zooms (ctrl+wheel), two-finger scroll also zooms here.
  • Touch: pinch to zoom on the centroid, drag to pan, touch-and-hold to read out.
  • Keyboard (focus a chart first): ←→ pan, +- zoom, Home/End to the extremes.
  • Presets and mode below each chart are just more writers to the same viewport.

1 · Single series, rate mode (a level)

CPU load as a percentage - already a rate, so it is zoom-invariant: averaging it when zoomed out is honest. Line/area form. Dense, evenly sampled. Scrub to see the tooltip interpolate between samples.

2 · Stacked ribbons, model spend (accumulating -> rate)

Three DeepSeek model streams. Each event is a cost that accumulates, so we plot a rate - pounds per hour - which means the same thing at every zoom. Stacked so total height is total spend rate; a 2px surface gap separates ribbons. The tooltip is a table: only the bottom ribbon sits on the baseline, so it does the real work of reading band heights. Irregular gaps in the data.

span mode

Switch to cumulative: the running total only ever climbs (total pounds spent since the start). Both views are zoom-invariant.

3 · Cumulative, energy from power (a level integrated)

Household power draw in kW, sparsely and irregularly sampled. In rate mode you read instantaneous kW; in cumulative mode the chart integrates it into kWh (energy) - the running total. This exercises rendering on sparse, gappy data.

mode

4 · Live-tailing (follow the newest data)

New samples arrive every 250ms. With follow on, the right edge stays pinned to the newest point. Pan or zoom away and follow releases; hit End (or pan back to the edge) to re-arm it. Two series, stacked.
